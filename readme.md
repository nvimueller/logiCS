## git guidelines

to maintain a clean and consistent repository history, all members are expected to follow these guidelines.

### commit message conventions

- **all lowercase**: write every commit message entirely in lowercase text. no exceptions.
- **imperative mood**: phrase messages as imperative commands (e.g., `add unit test` instead of `added unit test`).
- **concise & clear**: keep the summary line short and descriptive (under 50 characters when possible).

#### message format

`<short description>`
